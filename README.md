# Gestão Clínica

## Tema escolhido

Gestão Clínica — Saúde Digital.

## Integrante

- Andrew Motta Daher

## Tecnologias utilizadas

- Java
- Maven
- JUnit

## Como compilar o projeto

Certifique-se de ter o JDK e o Maven instalados. Na raiz do projeto, execute:

```bash
mvn clean compile
```

## Como executar os testes

Para executar todos os testes automatizados, utilize:

```bash
mvn test
```

Para limpar os arquivos gerados anteriormente e executar novamente toda a suíte de testes:

```bash
mvn clean test
```
